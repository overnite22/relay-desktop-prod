# Relay Desktop

Native Windows client (Rust, Slint) for [Relay](https://github.com/overnite22/relay-server-prod), the self-hosted remote connection manager, in the spirit of Remote Desktop Manager: ribbon, folder tree, credential vault, embedded sessions. Works with a Relay server or with a local encrypted database.

This repository receives the published versions. The first release is in preparation.
