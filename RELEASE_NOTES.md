First public release of Relay Desktop, the native Windows client for Relay.

- Ribbon, folder tree and session tabs in the style of Relay web and Remote Desktop Manager
- Embedded RDP (Microsoft RDP ActiveX control) and SSH sessions in tabs, Proxmox consoles
- Relay server source (device token) or local encrypted database
- Credential vault with folder inheritance, TOTP, quick connect, workspaces, availability view
- Markdown notes, attachments, bulk SSH commands, RDM import, backups, duplicates, sync sources
- Built-in update check ("Help → Check for updates")

The MSI is not code-signed yet: Windows SmartScreen may show a warning.
