## English

- You can now import or paste an SSH private key when editing a credential in the Desktop vault. The editor accepts OpenSSH and PEM keys, plus PuTTY PPK keys in the local vault, and supports encrypted keys with a passphrase.
- SSH entries linked to that credential directly or through a folder use the key the next time they connect.

## Français

- Vous pouvez désormais importer ou coller une clé privée SSH lorsque vous modifiez un identifiant dans le coffre Desktop. L'éditeur accepte les clés OpenSSH et PEM, ainsi que les clés PuTTY PPK dans le coffre local. Il prend en charge les clés chiffrées avec une phrase secrète.
- Les entrées SSH liées à cet identifiant, directement ou par héritage de dossier, utilisent la clé à leur prochaine connexion.
