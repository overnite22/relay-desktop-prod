## English

- Fixed an RDP disconnect when a server requires credentials to be entered again. Relay now allows the Windows credential prompt even when it has already supplied a password. The prompt does not offer to save the credentials.

## Français

- Correction d'une déconnexion RDP quand le serveur exige de ressaisir les identifiants. Relay autorise maintenant la boîte de dialogue Windows même si un mot de passe a déjà été fourni. Cette boîte ne propose pas d'enregistrer les identifiants.
